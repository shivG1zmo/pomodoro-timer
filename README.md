# PomoDomo Timer

A Pomodoro timer I built to get hands-on with vanilla JavaScript and CSS — 
no frameworks, no libraries, just the basics.

## Why I built this

Mostly to test myself. I wanted to see if I could build something 
functional from scratch without leaning on React or any other framework. 
Pomodoro timer felt like the right scope — small enough to finish, 
complex enough to actually learn something.

## Features

- 25 min work / 5 min break cycle
- Auto switches modes when timer hits 0
- Manual mode switch button
- Start, Pause, Reset controls
- Background changes color based on current mode

## Tech

HTML, CSS, JavaScript
